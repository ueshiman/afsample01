.NET 10 / C# / ASP.NET Core Web API / DI / Microsoft Agent Framework 必須で、POC向けの会話補助マルチエージェントサービスMVPを実装してください。

# 概要
1発話をAPIで受け取り、JSON定義ファイルで指定された複数エージェントで非同期評価し、結果をWebhookへ返す。
結果は基本的にエージェント単位で返す。
ただし、エージェント間で会話が発生した場合のみ conversationResult として集約結果を返す。

# 必須要件
- .NET 10
- Microsoft Agent Framework を利用
- Microsoft.Extensions.DependencyInjection による DI 構成
- BackgroundService で非同期実行
- 実行対象エージェントは agents.json から読込
- enabled=true のエージェントを実行
- 1要求あたり実行対象エージェント数は最大10件
- 上限超過時はエラー
- 一部エージェント失敗時も他の結果は返す
- ログを出す
- Webhook通知を行う

# 入力API
POST /api/messages/evaluate

Request:
{
  "conversationId": "conv-001",
  "messageId": "msg-001",
  "sentenceText": "この商品は必ず利益が出ます",
  "speakerRole": "operator",
  "timestamp": "2026-03-10T12:00:00Z"
}

必須項目:
- conversationId
- messageId
- sentenceText
- speakerRole
- timestamp

Response:
{
  "accepted": true,
  "jobId": "job-001",
  "status": "Accepted"
}

# Webhook通知
eventType は evaluation.completed のみでよい。
基本は agentResults を返す。
エージェント間で会話が発生した場合のみ conversationResult を追加する。

Webhook payload example:
{
  "eventType": "evaluation.completed",
  "jobId": "job-001",
  "conversationId": "conv-001",
  "messageId": "msg-001",
  "agentResults": [
    {
      "agentId": "compliance-agent",
      "agentName": "ComplianceAgent",
      "status": "Completed",
      "result": {
        "status": "warning",
        "reason": "断定的表現の可能性"
      }
    }
  ],
  "conversationResult": {
    "summary": "エージェント間の会話結果として注意喚起が必要と判断された。",
    "details": {
      "finalAssessment": "warning"
    }
  }
}

# agents.json 仕様
ファイル名: agents.json

例:
{
  "version": "1.0",
  "agents": [
    {
      "agentId": "compliance-agent",
      "agentName": "ComplianceAgent",
      "enabled": true,
      "systemPrompt": "あなたはコンプライアンス評価エージェントです。会話文を評価し、問題の可能性がある表現をJSONで返してください。",
      "model": {
        "deployment": "gpt-4o-mini",
        "temperature": 0.2,
        "maxTokens": 1000
      },
      "timeoutSeconds": 15,
      "outputFormat": "json"
    }
  ]
}

ルール:
- enabled=true の件数は最大10件
- agentId は一意
- 不正JSON、必須項目不足、上限超過はエラー
